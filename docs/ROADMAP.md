# Roadmap

## Phase 1 — foundation

- App shell and module navigation
- Versioned JSON configuration and modular runtime export
- Autoclicker and dynamic keybind settings
- Modular AutoHotkey v2 runtime lifecycle ownership
- Roblox window tracking and a basic status overlay
- Profile persistence and core tests

## Phase 2 — integration and overlay

- Structured v2 runtime IPC with state and error messages
- Live CPS/input telemetry
- Overlay drag/edit/lock experience with DPI and per-element persistence
- Completed: configurable PNG mana guide aligned to the focused Roblox client
- Remaining: live mana detection/telemetry if the overlay should reflect a measured mana value
- Key-capture control replacing text-only entry

## Phase 3 — additional modules

- Completed: profile-scoped Gate Macro notation editor and exact Roblox chat expansion
- Shared cooldown engine and indicators
- Profile import/export, duplication, and richer activation rules
- Additional macro modules with capability/availability checks
- Incremental native replacement of AHK behavior where regression coverage justifies it
